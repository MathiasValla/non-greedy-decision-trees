# Pattern Recognition Letters Submission Draft

This folder contains an Elsevier `elsarticle` submission draft for Pattern Recognition Letters.

- `main.tex`: manuscript source, using `elsarticle`.
- `highlights.txt` and `highlights.tex`: required Elsevier highlights.
- `graphical_abstract.pdf`, `.tiff`, and `.eps`: graphical abstract exports
  generated from original article-result artwork.
- `references.bib`: bibliography.
- `Fig1_accuracy_time.pdf` and `Fig2_forest_size.pdf`: manuscript figures.

The implementation and retained article results are documented in
`../REPRODUCING_RESULTS.md` and will be available from
<https://github.com/MathiasValla/non-greedy-decision-trees>.

The graphical abstract is generated by
`../scripts/make_prl_submission_extras.py`; the TIFF export is larger than
Elsevier's 531 x 1328 px minimum while preserving the requested aspect ratio.
