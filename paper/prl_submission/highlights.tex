\begin{itemize}
\item k-sighted trees score splits through optimized descendant subtrees.
\item Uniform extra sight gives small accuracy gains at large time cost.
\item Sparse farther-sighted trees improve mostly greedy bootstrap forests.
\item Mixed-sight forests can dominate lower-sight forests at fixed time budgets.
\item Open code and PMLB result tables support full reproduction.
\end{itemize}
