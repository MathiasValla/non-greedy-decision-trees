# Supplementary Review Materials

These anonymized tables support the Journal of Classification short-note
submission.

- `lookahead_aggregate_results.csv`: aggregate Table 1 values.
- `lookahead_accuracy_cost_deltas.csv`: accuracy and fit-time deltas.
- `lookahead_utility_thresholds.csv`: accuracy-time utility thresholds.
- `mixed_sighted_forest_grid_summary.csv`: summarized mixed-forest grid used in
  Figure 2 and the mixed-forest text.
- `mixed_sighted_dataset_sample.csv`: dataset names and dimensions for the
  mixed-forest benchmark sample.

The PMLB datasets are publicly available through the PMLB package. The custom
code can be provided to editors and reviewers upon request during peer review;
the public repository link is withheld from the anonymized manuscript to
preserve double-blind review.
