# Journal of Classification Submission Package

This folder contains a double-blind short-note package for the Journal of
Classification.

- `main_anonymous.tex` / `main_anonymous.pdf`: anonymized review manuscript.
- `title_page.tex` / `title_page.pdf`: non-anonymous title page and disclosures.
- `cover_letter.txt`: editable cover letter text.
- `Fig1_accuracy_time.pdf` and `Fig2_mixed_tradeoff.pdf`: manuscript figures.
- `Fig1_accuracy_time.eps` and `Fig2_mixed_tradeoff.eps`: vector figure exports
  for production-style illustration requirements.
- `supplementary_review_materials/`: anonymized result tables for review.

The Journal of Classification instructions specify a fully double-spaced,
single-column manuscript in English, at least 12pt font, wide margins, an
abstract of at most 150 words, explicit data and code availability statements,
and figures no larger than 4.8 x 6.8 inches.

Before submission, complete the full postal address and telephone number in
`title_page.tex` and `cover_letter.txt` or directly in Editorial Manager.

Figures are generated by:

```bash
python paper/scripts/make_joc_submission_assets.py
```
